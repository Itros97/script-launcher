Roadmap

Ideas, roughly in order. None of them is promised.

  • Calibre3D patterns and mat: buttons for patron <name> --real L A E and plantilla.
  • Calibre3D history: the list of past measurements, to open one again, and export them as CSV.
  • Calibre3D camera: the depth image beside the colour one, guides drawn over the live view (the cross and the circle), and a thumbnail of the last photo.
  • Arguments per script: a field on each script for arguments, saved with it.
  • Environment variables per script, read from an ignored .env file next to it.
  • Rename and reorder the saved scripts, and group them in folders.
  • Run history: keep the last few runs of each script, with their output, after the window closes.
  • Standard input: a field under the output to type answers to a script that asks.
  • Notifications when a long script ends while the window is in the background.
  • Copy output to the clipboard, and a search over it.
  • A monospaced font for the output, once Go UI offers one.
